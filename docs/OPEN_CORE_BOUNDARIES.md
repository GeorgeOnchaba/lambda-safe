# Lambda Safe Core: Open-Core Boundaries

Lambda Safe Core is the only open-source project in the NiGeNje ecosystem.

- License: Apache-2.0 (see LICENSE).
- Scope: the Rust source code, interfaces, documentation and tests contained in this repository.
- Contributions: accepted under the project's contribution terms; contributors retain their copyright and license
  their contributions under the project license.
- Distribution: public GitHub repository and public releases only.

## Separate proprietary product

Lambda Safe Enterprise is a separate proprietary commercial product of the NiGeNje ecosystem. It is not open source,
is not distributed through this repository, and does not inherit the Apache-2.0 license. Enterprise source, internal
architecture, commercial feature specifications and private documentation must never be published here.

## Boundaries for contributions and documentation

- Do not add Enterprise code, credentials, internal architecture, architecture diagrams, test evidence or commercial
  specifications to this repository.
- Public documentation may describe only Lambda Safe Core's own behaviour and interfaces.
- References to the wider NiGeNje platform must remain high level and must not disclose proprietary implementation.
- GitHub Sponsors, if activated, applies only to Lambda Safe Core and does not purchase Enterprise support.
