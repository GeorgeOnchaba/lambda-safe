# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
The project uses semantic versioning for implementation releases and separate
version identifiers for the language and certificate formats.

## [0.1.0] - 2026-08-24

### Added

- Greenfield λ-Safe contract language and JSON projection.
- Typed, unit-aware and authority-bounded semantic analysis.
- QF-LIA hard-fragment gate and SMT-LIB/Z3 process adapter.
- Separate assumption-feasibility and invariant-validity checks.
- Degrade and reconcile transition-preservation obligations.
- Linear token-use checking.
- Deterministic manifests and hard-only λ-certificates.
- Optional Ed25519 certificate signing and verification.
- Rust library API, CLI and stateless HTTP service.
- Schemas, conformance corpus, adversarial tests, fuzz targets and benchmarks.
- CI, container, Kubernetes, security and research-reproducibility resources.
